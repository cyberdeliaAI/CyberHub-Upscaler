# CyberHub Upscaler

Upscale images locally with tiled ONNX Real-ESRGAN models.

- Version: `1.1.1-beta`
- Channel: `beta`
- Publisher: `official`

## Installation

1. Open **Module Manager** in CyberHub.
2. Click **Check for updates**.
3. Find **Upscaler** and choose **Install** or **Update**.
4. Restart CyberHub when the installation finishes.

The ZIP attached to this repository's GitHub Release can also be imported manually through Settings.

## Python Packages

- `Pillow>=9.0`
- `numpy>=1.24`

## Beta Status

This is an official beta. Back up important files and report reproducible issues before relying on it in a production workflow.

## Privacy

CyberHub runs locally. A module uses an external service only when its function requires it and the user starts that action.
